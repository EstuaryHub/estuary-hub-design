# Decision Register

This register records decisions once their owner has reached an outcome. Detailed rationale stays in the linked design record; unresolved work remains in [Open Questions](../04-open-questions.md).

## How To Record A Decision

Add one row when a question is resolved. Update the owning design record and replace the question's status with a short link to this row while retaining the question's original context.
